# Mailkeep 0.1.8 public beta

Mailkeep is a Windows desktop email client. Download and run the x64 MSI to install it for your Windows user. This beta installer is unsigned and Windows may show a SmartScreen prompt.

Gmail and Outlook.com/Hotmail have been used with live accounts. The Yahoo, AOL, iCloud and Fastmail presets are available for testing. End-to-end setup, sending and receiving with those four providers are untested. If you encounter a problem, please [open a Mailkeep issue](https://github.com/GanizaniSitara/mailkeep/issues/new) with the provider, the action you took and the error message. Leave out passwords, verification codes and private mail.
